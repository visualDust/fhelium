# Contributing to FHElium

The maintained contributor guide defines source-tree preparation, change scope,
validation, documentation, and review requirements for FHElium contributions.
Read it before opening a pull request:

- [Rendered contributor guide](https://fhelium.550w.host/developer/contributing)
- [Contributor guide source](docs/developer/contributing.md)

Use [GitHub Issues](https://github.com/VisualDust/fhelium/issues) for reproducible
problems and concrete feature or documentation proposals. Use
[GitHub Discussions](https://github.com/VisualDust/fhelium/discussions) for usage
questions and open-ended design discussion.
